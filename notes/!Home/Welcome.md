# Welcome!

Questo è un semplice generatore di appunti statici, pensato per condividere i miei appunti, una volta finiti. 

## Come funziona
1. Aggiungi i tuoi file `.md` nella cartella `notes/`.
2. Il menu laterale si popola automaticamente basandosi sulla struttura delle cartelle.
3. Il browser renderizza tutto al volo; lo stile usato comprende il font Computer Modern, testo sillabato e giustificato come in un qualunque documento LaTeX.
